# SwastSetu AI — AI Healthcare Assistant for Bharat

![Concept](https://img.shields.io/badge/Status-Concept%20%26%20Design-blue)
![AI](https://img.shields.io/badge/Domain-Healthcare%20AI-brightgreen)

**SwastSetu AI** is a dual-mode, AI-powered healthcare system designed to bridge the
healthcare gap for rural and underserved populations across India.

> 📐 This repository currently holds the **system design and requirements** for the
> project — the architecture, problem framing, and product spec that precede
> implementation.

## 🎯 Problem
Rural and underserved communities face limited access to timely medical guidance.
SwastSetu AI aims to provide accessible, AI-assisted first-level healthcare support.

## 🧩 Approach (dual-mode)
- **Online mode:** richer AI capabilities when connectivity is available.
- **Offline / low-resource mode:** core guidance that works in low-connectivity areas.
